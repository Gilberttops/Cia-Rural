Nova baixa

Grava na aba Baixas (pagamentos recebidos da Ypoti). O código (B0001…) é gerado automaticamente.
Desconto e acréscimo ajustam a capacidade desta baixa para fechar as faturas escolhidas abaixo, sem alterar o valor em dólares realmente recebido. Use pra absorver diferenças pequenas de arredondamento ou descontos combinados com o cliente.

Código do Apps Script

O código do Apps Script (com geração automática dos códigos V0001…/B0001… e a função de preenchimento das linhas antigas) está no arquivo apps_script_ypoti.gs.txt, enviado junto com este dashboard. Cole o conteúdo dele em Extensões → Apps Script na planilha, depois Implantar → Gerenciar implantações → editar (✎) → Nova versão (ou Nova implantação → App da web se for a primeira vez).
Abas da planilha: Cargas e Chacobras para as vendas, Baixas para os pagamentos, Conciliacao para as ligações entre eles. Valores em dólares (US$). Cada venda e cada baixa tem um código sequencial (V0001…, B0001…) gravado na própria planilha — veja o arquivo apps_script_ypoti.gs.txt para o código e o passo a passo.
As ligações entre baixas e vendas são feitas por você na aba Conciliar. Com a API configurada (e o script atualizado), elas ficam gravadas na aba "Conciliacao" da própria planilha; sem a API, ficam salvas apenas neste navegador.
